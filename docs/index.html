SE3 day-ahead load forecast

Every morning an unattended job publishes tomorrow's hourly electricity load forecast for Swedish bidding zone SE3, then scores it against what actually happened. The comparison is a naive baseline: the same hour one week earlier.

Model versions. v1: Stockholm temperature only. v2 (from 23 Sep 2026): population-weighted temperature over nine SE3 cities. Each day's version is shown in the score table.

Backtest (held-out year Sep 2025–Aug 2026, observed temperature used as a perfect forecast, so optimistic): v2 MAE 269 MW (2.9 %), v1 306 MW (3.2 %), baseline 639 MW (6.6 %). The live numbers above use real SMHI forecasts and are the honest ones.

Data: ENTSO-E Transparency Platform (load), SMHI Open Data (temperature). Source and full forecast history in the repository.
